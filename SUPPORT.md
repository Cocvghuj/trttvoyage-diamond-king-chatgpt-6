# Support

- Bugs: use the Bug Report issue form.
- Improvements: use the Feature Request issue form.
- Security vulnerabilities: follow SECURITY.md; never use a public issue.
- Usage questions: check the README and linked docs first.

Include the repository, relevant path/page, expected and actual results, safe reproduction steps, and relevant environment details. Remove personal data, credentials, private URLs, and access tokens.

This is a community project space, not a guaranteed 24/7 support service. Do not use issues for emergencies or confidential account matters.

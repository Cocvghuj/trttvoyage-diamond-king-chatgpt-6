## 4. Hub-page linking

The Wellness hub should link to all ten articles using descriptive article titles. Each article should link back to the hub with a short contextual phrase such as **Explore more TRTT Wellness guides**.

Do not create a hub URL until the page exists and its canonical URL has been checked. Do not change the main site menu as part of this plan.

## 5. On-page implementation rules

1. Use descriptive anchor text that explains the destination.
2. Place links inside relevant paragraphs; avoid link lists that interrupt the article.
3. Keep the link count useful rather than forcing every suggested link into every article.
4. Add a link only when the destination is published, accessible, and factually relevant.
5. Use the exact canonical HTTPS URL from the live destination page.
6. Do not link to draft GitHub source files from public health articles as if they were reader resources.
7. Keep external authoritative medical sources distinct from internal TRTT links.
8. Do not add links that imply diagnosis, treatment, guaranteed confidentiality, or a specific service availability.
9. Preserve each article's existing medical disclaimer and trusted-source citations.
10. After editing, preview desktop and mobile layouts and check every link manually.

## 6. SEO implementation sequence

- **Stage A — Publish readiness:** Complete qualified medical review, image licensing / asset decisions, editorial review, and site-owner approval. These remain separate release gates.
- **Stage B — Publish in Blogger:** Enter each title, search description, custom permalink, labels, and approved image in Blogger fields. HTML comments do not automatically populate Blogger SEO fields.
- **Stage C — Capture canonical URLs:** Copy the exact live canonical URL for each published article and record it in the URL register below.
- **Stage D — Add contextual links:** Implement only the relevant links from Section 3; add the hub link when the hub exists.
- **Stage E — QA:** Check for 404s, redirects, wrong destinations, duplicate anchors, mobile layout issues, and links pointing to unpublished drafts.
- **Stage F — Search Console:** Request indexing only after the page is live and technically accessible. Internal links do not guarantee indexing or ranking.

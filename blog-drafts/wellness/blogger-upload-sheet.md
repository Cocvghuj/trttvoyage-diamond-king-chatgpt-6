## Blogger setup — apply these fields separately

For each post:
1. In Blogger, choose **New post** and paste the matching article HTML into the post editor's HTML view.
2. Set the post title using the **Blogger Post Title** column.
3. In **Search description**, paste the matching meta description (where Blogger's search-description setting is enabled).
4. In **Permalink**, choose **Custom permalink** and enter the slug exactly as listed. Blogger may append the site's date path; verify the final preview URL.
5. Add the labels exactly as listed.
6. Add a real, properly licensed, non-explicit image. Upload it to an image host/Blogger and insert its actual URL into the article's featured-image figure. Add the listed alt text.
7. Preview on mobile and desktop, check links and formatting, then save as **Draft** until editorial and medical review are complete.

**Important:** SEO Title, Meta Description, Permalink and Labels are recorded as HTML comments in each source file. Blogger does not automatically apply those comments to its post settings. Enter the fields manually. Do not publish a placeholder image or leave an empty featured-image block.

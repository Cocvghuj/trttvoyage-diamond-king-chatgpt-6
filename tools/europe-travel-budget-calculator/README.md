# Europe Travel Budget Calculator

A standalone, client-side TRTT Voyage estimate tool.

## Open
Open `index.html` in a modern browser or serve this directory from an authorized static host. The repository source URL is not itself a hosted application.

## Calculation rules
- Transport, activities and other costs are group totals.
- Accommodation is one room/rental total multiplied by trip days.
- Food and local transport are per traveller per day.
- The selected currency is a display/entry label only. No exchange-rate conversion occurs.
- No live airfare, hotel pricing, availability, booking or account connection is performed.
- All calculations run locally in the browser; this tool does not send entered values to a server.

## Validation
Travellers: integer 1–50. Trip days: integer 1–365. Cost inputs: finite, non-negative numbers. Invalid input is reported before recalculation.

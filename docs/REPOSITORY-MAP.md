# Repository Map

## Public command-center handbook
This repository contains public-safe operating documentation and reusable templates.

| Area | Purpose |
|---|---|
| `docs/` | Charter, workflow, architecture, and contribution guidance |
| `templates/` | Reusable logs, change records, and test reports |
| `examples/` | Sanitized examples only; never real credentials or private records |
| `releases/` | Public release notes and version summaries |

## Private operational vault
The companion private repository is `Cocvghuj/trtt-diamond-king-private-vault`. It is intended for private project state, internal decision history, and recovery notes. Do not copy its private contents into this public repository.

## Product repositories
TRTT Voyage application/theme source and other product code should remain in their designated project repositories. This handbook is not a substitute for the source-of-truth code repository.

## Repository hygiene
- Keep the public repository free of secrets and private personal data.
- Use feature branches for changes.
- Link to a project only when the URL has been verified.
- Keep a clear distinction between source code, documentation, backups, and release artifacts.

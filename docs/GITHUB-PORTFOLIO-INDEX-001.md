## 4. Repository page standard

For repositories owned and maintained by TRTT, the public-facing landing page should use clear English and, where relevant, include:

1. Project name, one-sentence purpose, and current status.
2. Owner/maintainer identity: Engr. Abu Taher / TRTT Voyage.
3. Quick links: website, live demo (only if verified), documentation, releases, issues, and source.
4. What the project does and does not do.
5. Screenshots or diagrams only when they represent the current implementation.
6. Requirements, installation, configuration, and safe usage.
7. Privacy/data handling and security reporting.
8. License and third-party attribution, matching the actual repository license.
9. Contributing guide and code of conduct when appropriate.
10. Known limitations, test evidence, changelog, and next steps.
11. Clear disclaimer: AI assistance, third-party services, travel/financial/technical limitations, and affiliate disclosures where relevant.

Do not replace upstream README files, licenses, security policies, or contribution rules in forks. Add a clearly labelled TRTT-local note only when it is useful and license-compatible.

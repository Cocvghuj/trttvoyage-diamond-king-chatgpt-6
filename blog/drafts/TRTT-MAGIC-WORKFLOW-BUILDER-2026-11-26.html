TRTT Magic Workflow Builder: A Free Tool to Plan and Validate Your Workflow

Good workflows make complicated work easier to understand. Before connecting apps or automating a process, it helps to write down what should happen, in what order, and what a successful result looks like.

The TRTT Magic Workflow Builder is a free, browser-based planning tool for creating a simple workflow, checking that key stages are present, and exporting the plan as a JSON file. It is designed for creators, small teams, bloggers, and anyone who wants to make a repeatable process clearer before attempting automation.

What can the tool do?

  • Build a workflow: add, edit, and remove steps in a process.
  • Use practical stages: choose Trigger, Check, Fix, Memory Update, GitHub Save, Blog Post, Result, and other step types.
  • Validate the structure: check for the required Trigger, Check, Fix, GitHub Save, and Result stages.
  • Preview the plan: inspect the workflow as formatted JSON.
  • Copy or export: copy the JSON or download it as a file for later use.

How to use TRTT Magic

  1. Open the TRTT Magic Workflow Builder source file on GitHub.
  2. Download the HTML file and open it in a modern browser.
  3. Give your workflow a clear name.
  4. Edit the sample steps or add new ones. Describe what each step should do.
  5. Select Check workflow to find missing stages or descriptions.
  6. Preview the JSON, then copy it or choose Export JSON.

A simple workflow example

A content-production workflow might follow this sequence:

  1. Trigger: an authorised content request arrives.
  2. Check: verify the topic, sources, and existing material.
  3. Fix: correct issues and review the draft.
  4. Memory Update: append a dated progress note.
  5. GitHub Save: save the reviewed version to the approved branch.
  6. Blog Post: prepare the approved article for publication.
  7. Result: record what was tested, saved, and published.

Privacy and limitations

The current version runs in the browser tab. It does not require an account, backend, or external library. Workflow details are held in page memory and are not saved by the tool to a server. Export your JSON if you want to keep a copy.

Important: this is a workflow planning and JSON-export tool. It does not connect to GitHub, Blogger, Make.com, or other services; it does not run automations, publish posts, or deploy software. Those integrations would require a separately built and tested version with explicit permissions.

Who may find it useful?

Bloggers can map their editorial process. Developers can outline release checks. Small teams can document handoffs. Beginners can learn to break a large task into clear, testable steps.

Try it and share feedback

Open the TRTT Magic Workflow Builder file on GitHub, download it, and run it locally in your browser. Feedback about missing step types, clarity, and accessibility can guide future improvements.
